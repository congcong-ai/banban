# 接线与安全试听

目标：ESP32-S31-Korvo-1 V1.1 / ESP32-S31-WROOM-3。不能使用ESP32-S3固件。

1. Power USB-C接稳定5V电源；UART USB-C接Mac数据线用于烧录与日志。供电能力参照官方板卡要求，不因能亮屏就判断有足够余量。
2. CX31993（VE Abigail Pro，USB-C输入、3.5mm耳机母座）通过已有USB-A公→USB-C母转接头，接开发板USB-A Host。下游标称最大500mA。转接头是否传数据必须用枚举日志验证。
3. 初次只接已知正常的3.5mm耳机。必要时先在电脑/手机单独验证DAC和转接头。P1为低音量测试音：左440Hz一秒、右880Hz一秒、双声道一秒、静音一秒循环。
4. 耳机测试通过后再连接D100。使用已核验L/R/GND的三极TRS→红白双RCA线；DAC软件音量和音箱音量先调低。

已有照片中的三道绝缘圈意味着四极TRRS，不意味着4.4mm。另一端和CTIA/OMTP接线未核验，不据外观猜线序。不要把该线直接认作普通TRS→RCA。

CX31993是耳机输出，不是固定2Vrms Line Out。输出电平、底噪、失真需要试听/测量；软件增益不能保证实际声压。板载左右扬声器端子是功放输出，禁止接D100 RCA。

伴伴P1不启动LCD，屏幕无画面不代表固件未运行，以UART日志为准。

## UART Type-C与有源音响

UART Type-C连接USB转串口桥，只用于开发；Power Type-C仅供电。它们不能承载CX31993所需的Host音频流。现有A转C转接头在USB-A Host上已读出描述符并完成非零等时传输，继续保留此连接。

耳机不是最终系统的必需部件。DAC模拟输出经已核验TRS→双RCA连接D100，是目标有源音响路线。当前耳机无声尚在定位，不能通过换接RCA来绕过尚未验收的模拟输出，也不将TRRS未知线序试接当作修复。
