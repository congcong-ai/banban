# 实体四键控制

## 使用

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| PLAY（参考BSP名MODE，第三档） | 原曲 ↔ 上次消原唱模式 | 暂不绑定 |
| SET | 基础消除 ↔ 保留伴奏；处于原曲时只选择下次模式 | 暂不绑定 |
| VOL+ | 消除强度+5，最大100 | 每200ms连续调整 |
| VOL- | 消除强度-5，最小0 | 每200ms连续调整 |

上电为原曲，消原唱预选BASIC_CUT，强度100。此选择基于用户实听：基础100明显削弱原唱；MUSIC_PRESERVE的65和100在当前试听歌曲上削弱不足，100伴奏更好但人声几乎不变。不能将保留模式宣传为已获得相同消除效果。播放音量仍由手机及串口`volume`独立控制，VOL±不是播放音量。

模式和强度沿用DSP的20ms平滑。ADC每约20ms采样一批四次均值，使用优先级2、3072字节栈的独立任务；高优先级按键定时器仅读取原子缓存，缓存超过100ms未更新则视为释放。按键回调只更新原子参数和事件日志，不在蓝牙回调执行DSP，不直接操作USB句柄。按键初始化失败记录错误并继续音频。未启用LCD、板载喇叭或NVS持久化；重启回到默认值。不绑定长按清除配对，避免无意删除配对记录。

## 只读参考与许可

读取SmartBadge所附的Espressif S31 BSP：`vendor/espressif/esp32-s31-korvo/components/esp32_s31_korvo/esp32_s31_korvo.c`（按键段）、`esp32_s31_adc_calibration.c`和`priv_include/bsp_adc_calibration.h`。未修改参考文件，未复制SmartBadge业务代码。

上述校准源码声明2026 Espressif版权及Apache-2.0，已读取；校准C文件和头文件原样复制到本工程`components/controls/`并保留声明。固定参考工程来源提交见既有审计文档，实际复制文件哈希如下：

- `esp32_s31_adc_calibration.c`：`080c644e1e21048fd56e0940bfdc319d7edf357338a20400849c475e1b7b9f61`
- `bsp_adc_calibration.h`：`e73faf01b5f31a31447dfd13273b06f9a0452f732221aa37529b8e08897d86ad`

ADC为GPIO42 / ADC1_CH0_N、0dB、默认位宽，使用同一S31软件校准。参考BSP电压中心380/820/1340/1870mV、空闲2000mV；边界按相邻中心中点得160/600/1080/1605/1935mV，不猜测通用S3阈值。本封装使用互不重叠的开闭区间，避免恰好边界时两键同时激活。

去抖与短按/长按事件复用乐鑫`espressif/button ==4.2.1`，与参考已锁定版本一致；组件包`license.txt`为Apache-2.0，接口及实际源码已读取。组件由管理器下载并锁定，不复制其完整源码到版本库。校准只在音频和蓝牙启动前执行一次，避免播放中执行大批ADC采样。
