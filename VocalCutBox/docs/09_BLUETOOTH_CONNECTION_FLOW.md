# 手机、电脑与电视的无屏幕连接

日期：2026-10-27。按用户最新偏好：不用屏幕、不要求在开发板输入PIN或核对数字；未连接时允许用户直接从系统蓝牙列表选择连接，已连接时阻止另一台设备抢占。

## 音频方向

手机/电脑/支持A2DP蓝牙音频输出的电视为Source，伴伴为Classic Bluetooth A2DP Sink。收到的音频包含原唱与伴奏，DSP本地处理后通过USB-A→CX31993→模拟输出送耳机或有源音响。

只支持BLE遥控器的电视不等于支持A2DP音频输出。具体电视是否可用，需要它提供“蓝牙扬声器/耳机/音频输出”功能；不预先承诺所有电视支持。手机播放器作为普通系统音源，不需要音乐App SDK。

UART Type-C是烧录/串口桥，不能作为手机或电脑的USB音频输入；本版音源通过蓝牙进入。USB-A已用于Host连接DAC。

## 自动配对流程

代码已配置以下行为，实际真板配对结果另记测试日志：

1. 上电初始化Classic控制器、Bluedroid及A2DP Sink，广播名 `VocalCutBox`，进入可发现/可连接状态。
2. 手机/电脑在系统蓝牙设置中点选设备。SSP采用NoInputNoOutput / Just Works，开发板自动确认，不要求输入PIN或抄录数字。手机系统可能仍弹一次“配对”确认，不能绕过系统自身要求。
3. 连接成功后关闭发现及新的连接入口，防止第二台设备抢占；当前连接保持工作。
4. 原设备主动断开、关闭蓝牙后，自动重新变成可发现/可连接；已有配对记录可保留，音源侧可自动重连。
5. 不支持必须输入旧式PIN的配对路径，不把0000密码输入流程当作“免验证”。

S31控制器必须使用 `CONFIG_BTDM_CTRL_MODE_BR_EDR_ONLY=y`，而不只设置主机的 `CONFIG_BT_CLASSIC_ENABLED=y`。首次运行暴露控制器仍为BLE-only导致初始化未完成，已按官方A2DP示例修正，历史失败保留。

连接名、音频服务类、SSP和发现控制不依赖LCD、按键或板载喇叭。因此第一次连接无需在开发板上做任何操作。

## 四个按键与声音提示

2026-10-28已接入四键：PLAY原曲/消原唱切换，SET选择两种消除模式，VOL±调整消除强度（短按5、长按重复）。默认原曲，首次消原唱为用户试听有效的BASIC_CUT、强度100。播放音量单独控制，详细说明及验证状态见[四键控制](10_BUTTON_CONTROLS.md)。未绑定PLAY长按删除配对；屏幕与提示音均不影响系统蓝牙自动配对。

板载喇叭保持关闭，尚未接入连接提示音。本次不为按键启用LCD、相机或ES8389。
