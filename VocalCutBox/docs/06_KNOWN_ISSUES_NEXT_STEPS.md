# 已知问题与下一步

## 当前优先事项

UAC2已通过第三方MIT组件复用移植，真板可以查询并设置48kHz/16bit/2ch，官方UAC1不支持的阻碍已有实现路径。**用户已确认48kHz/32bit耳机实际出声、左右正确**；16bit路径无声差异仍保留，D100尚未连接。

诊断确认PCM非零、实际USB完成字节数增长、无跳过包、DAC主mute=0、左右-12dB读回一致。Mac上的同一DAC/耳机基线已通过；32bit端点所需FIFO已修复并通过试听。不能把TRRS外观当作无声原因，也不要求先购买硬件。

## 实现边界与后续验收

- 当前UAC2后端仅支持全速1ms调度；明确拒绝高速125us流。可以满足目标48kHz立体声，不支持任意高速格式。
- 本只DAC播放使用时钟9，录音时钟10不打开；尚不提供通用多时钟或双工支持。
- USB热拔插、耳机左右可闻、D100已核验TRS/RCA线输出均需真实验收。耳机32bit通过；用户当前无法接D100，保留音箱验收。
- 蓝牙A2DP→UAC2已成功上板配对，但此前音乐无声。已为06cb:1595增加16→32兼容初始化，USB独立版重插试听通过，蓝牙修复版已由用户确认音乐基本正常；轻微噪声在音量归零再恢复后未再听到，需复测。线性SRC没有高品质带限滤波或独立时钟漂移补偿。
- 四键实体识别与PLAY实际切换已通过；新增采样曾暴露ADC/PHY跨核锁死，改为同核后超过10分钟连续播放未复现，60分钟仍待完成。AVRCP音量映射、主动回连、配对清除、LCD、NVS节流保存未完成。
- DSP主机测试通过；真实歌曲、CPU负载、端到端延迟、10/60分钟音频稳定性尚未验收。USB发送持续10分钟不能替代全程听音。

历史UAC1枚举上限、UAC2拒绝与驱动空指针问题保留在真板日志和技术决策中；当前默认已切换到复用UAC2后端。
